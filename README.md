# Angler's Pocket

Angler's Pocket is a World of Warcraft addon that shows a Fishing button
when a fishing pole is equipped and lists the baits in your bags next to it.

Supported clients: WoW Forever, Classic Era, TBC Anniversary and Mists of Pandaria Classic.

## Features
- Fishing button with tooltip and click-to-cast.
- Key binding to cast Fishing, set directly in the config window.
- Bait buttons for all supported bait items in your bags, sorted by item ID, with stack counts.
- One-click apply bait to main hand.
- Remaining bait time shown in the corner of the Fishing button (red below one minute).
- Optional pulsing highlight on the bait buttons while no bait is applied.
- Adjustable button size; baits can be shown below or beside the Fishing button.
- Optional sound adjustment while a fishing pole is equipped (effects, music and ambience volume, each with its own slider). Your normal volumes are restored when you unequip the pole or log out.
- Config window to unlock and move the button stack and change all options.

## Usage
- Equip a fishing pole to show the buttons.
- Click the Fishing button (or press your cast key) to cast.
- Click a bait button to apply it to your main hand.
- Open the config window with `/ap`:
  - **Cast key:** left-click the button, then press a key (Shift/Ctrl/Alt combinations work). Escape cancels, right-click removes the binding.
  - **Button size** and **Show baits beside the button** change the layout.
  - **Sound while fishing:** enable it and set the volumes that apply while a pole is equipped.

### Slash Commands
- `/ap` or `/anglerspocket` - toggle the config window.
- `/ap unlock` - unlock the buttons for dragging.
- `/ap lock` - lock the buttons.
- `/ap glow` - toggle the bait highlight while no bait is applied.
- `/ap reset` - reset position to default.
