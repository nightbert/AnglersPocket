# Angler's Pocket

Angler's Pocket is a World of Warcraft Classic addon that shows a Fishing button
when a fishing pole is equipped and lists available baits below it.

## Features
- Fishing button with tooltip and click-to-cast.
- Bait buttons for all supported bait items in your bags, sorted by item ID.
- One-click apply bait to main hand.
- Fishing buff cooldown displayed on the Fishing button.
- Simple config window to unlock and move the button stack.

## Usage
- Equip a fishing pole to show the buttons.
- Click the Fishing button to cast.
- Click a bait button to apply it to your main hand.

### Slash Commands
- `/ap` or `/anglerspocket` - toggle the config window.
- `/ap unlock` - unlock the buttons for dragging.
- `/ap lock` - lock the buttons.
- `/ap reset` - reset position to default.
